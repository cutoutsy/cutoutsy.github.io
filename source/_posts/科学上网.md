#### 自建代理：Shadowsocks / V2Ray

如果你有一定技术基础，也可以自己搭建代理服务：

**V2Ray** 是目前比较流行的代理工具，支持多种协议，隐蔽性好。

**Clash** 是新一代代理客户端，支持订阅、规则分流等功能。

### Linux 下配置代理

在 Linux 下可以使用 [Clash for Windows (Linux版)](https://github.com/clash/clash-for-linux) 或命令行工具：

```bash
# 安装 v2ray
bash <(curl -L https://raw.githubusercontent.com/v2fly/fhs-install-v2ray/master/install-release.sh)

# 配置并启动
v2ray run -config /path/to/config.json
```

配合系统代理设置或浏览器插件（如 SwitchyOmega）使用。

### 浏览器插件推荐

- **SwitchyOmega**：Chrome/Firefox 代理管理插件

### 常见问题

**Q: 免费 VPN 安全吗？**
A: 大部分免费 VPN 存在隐私风险，建议使用付费服务或自建代理。

**Q: iOS 上如何科学上网？**
A: 可以使用支持 iOS 的 VPN 应用，或使用 Shadowrocket、Stash 等代理工具（需配合订阅链接）。

**Q: 代理速度慢怎么办？**
A: 选择优质线路，避开高峰期；也可以尝试不同的代理协议。
